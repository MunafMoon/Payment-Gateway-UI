# Payment Gateway UI

A responsive React checkout interface built with Vite.

## Requirements Covered

- Multiple payment options: Cards, UPI, and Net Banking
- Dynamic input forms with live validation
- Order summary sidebar with cost breakdown
- Mock payment simulation with loading, success, and error states

## Features

- Sidebar-based payment method selection
- Separate payment components for Cards, UPI, and Net Banking
- Card number, expiry date, CVV, and UPI ID validation
- Responsive checkout layout for desktop and mobile

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
